# Eindreflectie

Translation at the bottom for Nils 🙂

Het project begon wat lastig. Ik wist namelijk vrijwel direct dat ik de Artifaction wilde doen, maar ik had geen idee wat. Toen werd er iets verteld over een techniek met guasian blur en contrast, deze techniek ken ik en gebruik ik wel eens om pixelige plaatjes "scherper" te maken en ik heb er wel eens een animatie mee gemaakt.
Dit was in ProCreate een programma gebaseerd op pixels, dus het leek me leuk om dat responsive in code te maken.
Toen ben ik eigenlijk een soort rabbithole ingevallen en een beetje de opdracht uit het oog verloren. Het eindresultaat is dus wel iets waar ik heel trots op ben en over kan zeggen dat ik er echt iets van het geleerd. Ik heb het gevoel dat ik enigzins heb gepusht tot wat CSS kan binnen een bepaald gebied.
Maar tegelijkertijd vind ik het niet héél erg bij artifaction passen.

## Wat ging goed?
Allereerst heb ik het super naar mijn zin gehad en merkte ik dat het onderwerp me echt interesseerde. Dat ik er verder en verder en verder aan wou werken, ik heb mezelf een aantal keer om 00:30 betrapt op dat ik er nog steeds mee bezig was. Dit was voor mij super fijn om te merken, dit is echt een project geweest waar ik energie van kreeg.

Ik heb het idee dat ik flink wat nieuwe dingen heb geleerd en dat ik vloeiender ben geworden in het schrijven van CSS, dat is een van mijn leerdoelen en daar ben ik super blij mee.

Het eindproduct vind ik goed gelukt, al is het een soort van half af vanwege dat ik op het laatst problemen kreeg met het gebruiken van een "random" gegenereerde property. Ik heb de knop die die functie aanroept wel laten staan omdat ik dat voor het eindgesprek van belang vind.

## Wat ging minder?
Ik merk dat troubleshooten op mezelf matig gaat. Snel heb ik het gevoel dat ik het "gewoon niet weet".
Dan ben ik snel geneigd om het aan AI te vragen omdat die een snel antwoord geeft. Wel lukte het goed om kritisch te kijken naar wat AI schreef en dat te implementeren in plaats van te kopieeren. Vaak was het toch wel zo dat AI compleet random dingen schreef waar ik uiteindelijk niks aan bleek te hebben. Aan het einde van het project liep ik tegen een probleem aan met het gebruiken van een random value, hierin heb ik samen met Nils alle mogelijke problemen doorlopen en het was voor mij super fijn om te zien hoe Nils dat troubleshooten aan pakte.

De tussentijdse reflectie's ben ik vaak compleet vergeten en heb ik dus ook grotendeels niet gedaan. Dit komt voornamelijk omdat ik zodra ik in de les kwam enthausiast aan de slag ging met het verbeteren van het project maar daarin dus compleet vergat op te schrijven wat ik deed.

Ook heb ik vaak dat ik heel lang aan hele kleine dingetjes zit te sleutelen terwijl ik eigenlijk beter kan werken aan de volledige basis op niveau krijgen.
